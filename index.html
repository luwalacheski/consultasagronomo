Bem-vindo ao SisAgro 1.0 - Unidade Capanema

Uma plataforma integrada voltada para o gerenciamento de propriedades rurais, otimização de safras e controle automatizado de consultorias prestadas por engenheiros agrônomos.

Este sistema conecta a interface Web ao banco de dados SQLite para gerenciar de forma eficiente ordens de serviço, análise de solo, visitas técnicas e vendas de insumos.

🚀 Módulos Práticos do Sistema:

Módulo Descrição Operacional
👥 Clientes Cadastro de produtores rurais, histórico de safras e controle de laudos da propriedade.
🌱 Serviços Catálogo de serviços técnicos como análise de solo, manejo de pragas e projetos de irrigação.
💰 Vendas Registro de transações comerciais, orçamentos de insumos e venda de infoprodutos agrícolas.
📅 Agendamentos Abertura de ordens de visita técnica a campo, alocação de horários e planejamento de vistorias.
🔍 Consulta Acompanhamento em tempo real das datas agendadas e status das consultorias solicitadas.

📊 Estrutura Tecnológica

  • Ambiente de Aplicação: Gestão comercial e assistência técnica para o Agronegócio.
  • Backend: Node.js com Express e API RESTful para processamento de dados.
  • Banco de Dados: SQLite (`sisagro.db`) integrado para persistência de registros e históricos.
